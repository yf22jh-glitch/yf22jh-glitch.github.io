개인정보처리방침

Kaga Finder는 Mac에서 실행되는 파일 탐색기예요. 이 문서는 앱의 Google Drive 연결을 포함한 데이터 접근·사용·보관·공유 방식을 설명해요.

접근하는 정보와 목적

  • 파일·폴더 이름, 경로, 고유 ID, 크기, 수정 시각 등의 정보: 목록·트리 표시, 검색, 선택한 항목 확인과 파일 작업에 사용해요.
  • 파일 내용: 사용자가 요청한 다운로드·업로드·복사·미리보기·편집·비교 등의 기능에 사용해요.
  • 파일과 폴더의 변경: 사용자가 실행하거나 설정한 작업에 따라 이름 변경, 이동, 휴지통 이동·삭제, 업로드와 동기화를 수행해요.
  • OAuth 인증 정보: 사용자가 허용한 Google Drive에 연결하고 연결을 갱신하는 데 사용해요. Google 비밀번호는 앱에서 수집하거나 저장하지 않아요.
  • 연결 이름·설정·즐겨찾기와 작업 기록: 사용하는 Mac에서 연결을 복원하고 작업 상태·복구 결과를 표시하는 데 사용해요.

어디에 보관하나요?

계정별 OAuth 토큰과 앱 비밀값은 macOS 키체인에 저장해요. 연결 설정·작업 기록은 Mac의 앱 지원 폴더에, 다운로드한 파일은 사용자가 선택한 위치에 저장해요. 미리보기·원격 편집·전송에 필요한 로컬 임시 사본과 복구 자료가 남을 수 있으며, 앱에서 해당 작업과 정리 상태를 확인할 수 있어요.

Google Drive의 원본 파일은 Google에 남아요. 앱은 연결한 저장소의 API와 직접 통신하며, 앱 개발자의 서버에 사용자 파일이나 인증 정보를 모으는 기능을 제공하지 않아요. 파일·작업 기록의 보관 기간은 사용자의 파일 관리와 앱의 임시 자료 정리에 따라 달라져요.

데이터의 공유와 사용 제한

Google 사용자 데이터를 광고, 판매, 신용 평가 또는 일반 AI 모델 학습에 사용하지 않아요. 개발자가 원격으로 사용자 Drive를 열람하는 기능도 없어요. 사용자가 파일을 다른 저장소로 복사하거나 외부 앱·공유 기능을 실행한 경우에는 선택한 대상에 작업에 필요한 정보가 전달돼요.

Kaga Finder의 Google API 데이터 사용·전달은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 따라요.

연결 해제와 삭제

앱에서 연결을 삭제하면 해당 연결 설정·즐겨찾기와 저장된 키체인 인증 정보를 제거해요. Google 계정의 제3자 앱 연결 관리에서도 Kaga Finder의 접근 권한을 철회할 수 있어요. 앱에서 연결만 삭제하는 동작은 Google의 동의 철회를 대신하지 않아요.

업무·개인 계정은 서로 다른 연결로 저장돼요. 한 연결을 삭제해도 다른 연결의 인증 정보나 파일을 함께 삭제하지 않아요. Google 계정에서 앱의 접근 권한을 철회하면 같은 계정으로 연결한 다른 기기에서도 다시 인증해야 할 수 있어요.

이미 내려받은 파일, 편집 초안, 임시·복구 사본과 작업 기록은 연결 삭제와 별도로 관리해 주세요. Google Drive의 파일을 지우려면 해당 파일의 삭제 작업을 직접 실행해야 해요.

보호와 문의

Google 로그인과 Drive API 연결은 암호화된 통신을 사용하고, 계정의 비밀값은 키체인으로 관리해요. 사용하는 Mac과 로그인 계정에 접근할 수 있는 사람의 권한도 파일 보호에 영향을 줘요.
