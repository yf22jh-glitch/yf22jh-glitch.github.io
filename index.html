Kaga Finder
개인정보처리방침이용약관
개인용 macOS 파일 탐색기

Mac의 파일과 연결한 저장소를 한곳에서.

Kaga Finder는 Mac에서 파일을 탐색·검색하고, 폴더 사이에서 복사·이동하는 데스크톱 앱이에요.

1~4개 패널

여러 폴더를 나란히 열고, 폴더 트리와 전체 경로를 보며 작업해요.

이름·확장자 검색

파일과 폴더를 검색하고, 결과를 선택해 해당 위치로 이동해요.

Google Drive·OneDrive

직접 승인한 계정의 목록을 탐색하고 파일을 내려받거나 올려요.

직접 관리하는 연결

서버와 공유 폴더를 연결하고, 진행 중인 전송과 작업 결과를 확인해요.

Google 로그인이 필요한 이유

Google Drive를 앱에서 탐색하고 파일을 전송하려면 Google의 동의 화면에서 접근을 허용해야 해요. 각 사용자는 자기 Google 계정으로 로그인하며, 계정별 인증 정보는 사용하는 Mac에 별도로 저장돼요. 앱 등록자의 Drive에 사용자 계정이 합쳐지지 않아요.

기존 Drive 파일을 탐색하고 수정·이동·삭제하는 파일 관리 기능을 위해 Drive 접근 범위를 요청해요. Google 비밀번호는 Google 로그인 화면에서 입력하며 Kaga Finder가 보관하지 않아요.

이 앱은 개인용으로 개발 중이에요. Google의 검증을 완료한 앱이라고 표시하지 않으며, 현재 사용·검증 범위는 Apple Silicon Mac이에요.

데이터 처리와 연결 해제 방법은 개인정보처리방침, 사용 조건은 이용약관에서 확인해 주세요.
