앱의 제공 범위

Kaga Finder는 개인용으로 개발 중인 macOS 파일 탐색기예요. 로컬 파일과 사용자가 연결한 저장소를 탐색·검색하고 파일 작업을 실행해요. 모든 기기·OS·저장소의 호환성이나 중단 없는 동작을 보장하지는 않아요.

사용자의 계정과 파일

사용자는 접근 권한이 있는 파일과 저장소를 연결해 주세요. Google 등 외부 서비스의 계정은 사용자가 직접 인증하며 각 제공업체의 이용 조건도 적용돼요. 파일의 이동·삭제·편집·동기화는 사용자가 선택하거나 설정한 작업에 따라 실행돼요. 중요한 파일은 별도 백업을 유지하고 작업 대상과 결과를 확인해 주세요.

외부 서비스

저장소 제공업체의 요청 제한, 인증 만료, 서비스 중단 또는 정책 변경으로 일부 연결이 제한될 수 있어요. 앱 사용은 외부 서비스의 요금제나 저장 공간을 포함하지 않아요.

데이터와 사용 중단

데이터 처리 방식은 개인정보처리방침을 따라요. 사용자는 연결 삭제·제공업체 접근 권한 철회·앱 제거로 사용을 중단할 수 있어요. 앱 제거만으로 이미 저장된 파일이나 모든 로컬 자료가 삭제되지는 않아요.
